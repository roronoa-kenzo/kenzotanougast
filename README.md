# Portfolio — Kenzo Tanougast

Portfolio personnel d'un développeur fullstack freelance.
Inspiration artistique : Nintendo Wii U / Miiverse, typo large, animations fluides.

## Stack

- Next.js 14 (App Router) + TypeScript strict
- Tailwind CSS
- Framer Motion

## Développement

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run start` — lance le build
- `npm run lint` — ESLint
- `npm run typecheck` — vérification TypeScript

## Contenu

Le contenu est déclaratif et centralisé dans `/data` :

- `data/profile.ts` — infos perso / liens
- `data/projects.ts` — projets
- `data/experiences.ts` — expériences pro
- `data/music.ts` — piste du moment
